# 메모리 브리프 · Memory Brief

삼성전자·SK하이닉스의 국내외 공개 뉴스와 목표주가 관련 기사를 한곳에서 보는 개인용 웹 대시보드입니다. Python 3.11 이상만 필요하며 별도의 패키지 설치나 API 키가 필요하지 않습니다.

## 실행

```bash
cd /workspace/memory-report
python app.py --port 8000
```

브라우저에서 실행한 서버의 포트 8000에 접속합니다. 기본 바인딩은 `127.0.0.1`입니다. 호스팅 환경에 배포할 때에는 해당 환경의 포트 전달 방식을 확인하고 필요하면 `--host 0.0.0.0`을 사용하세요. 현재 버전은 개인용이며 로그인 기능이 없습니다. 인터넷에 공개하기 전에 인증을 추가해야 합니다.

## 포함된 기능

- Google News RSS를 이용한 국내·해외 뉴스 수집: 기업별 국내 뉴스, 영어 뉴스, 목표주가 관련 뉴스 총 6개 피드
- 시작 시 현재 예약 구간 수집, 이후 매일 **한국 시간 오전 8시 / 오후 6시** 수집
- 지금 수집하기, 기사 제목·언론사 검색, 기업·지역·주제별 필터
- 제목·언론사가 같은 기사의 중복 저장 방지, HBM·DRAM·NAND·리포트 관련 기사 분류
- 최근 72시간 기사에서 주제와 출처를 분산한 핵심 기사 최대 3개 표시
- 원문 출처·발표 시각 표시, 브라우저에 기사 북마크 저장
- 원문 확인 후 목표주가·증권사·투자의견·변경 사유 수동 기록 및 삭제
- SQLite 영구 저장, 수집 실패 시 기존 데이터 유지, 수집 상태 표시
- 실제 데이터와 분리된 **예시 화면**: 가상 데이터는 DB에 저장되지 않습니다.

## 수집 범위와 제한

수집에는 HTTPS `news.google.com` 접근이 필요합니다. 현재 클라우드의 도메인 허용 설정이 반영되지 않았다면 설정에서 허용하고 다시 수집하세요. 원문을 여는 사용자의 브라우저에서는 해당 언론사 접속도 필요할 수 있습니다.

기본 수집 범위는 최근 3일 뉴스, 최근 7일 목표주가 관련 뉴스입니다. RSS 제공 범위 내의 기사만 수집하며 모든 기사나 모든 증권사 보고서의 포괄적 수집을 보장하지 않습니다. 원문 전문·유료 자료를 수집하지 않습니다. 영어 기사는 원어로 표시합니다.

핵심 브리핑은 **기사 제목을 선별한 목록**이며, 생성형 AI의 본문 요약이나 투자 영향 분석이 아닙니다. 주제 분류는 제목 키워드 기반입니다. 같은 제목·같은 언론사의 중복은 제거하지만, 여러 매체가 표현을 바꿔 쓴 동일 사건은 별도 기사로 남을 수 있습니다. 목표주가 관련 뉴스와 실제 증권사 원문을 구분하고, 금액·투자의견은 자동 추정하지 않습니다. 수동 기록은 입력자가 원문을 확인한 내용이며 서비스가 독립적으로 검증한 자료는 아닙니다. 주가·수익률 시세는 제공하지 않습니다.

**정기 수집에는 서버가 계속 실행 중이어야 합니다.** 클라우드 작업이 종료되면 수집도 멈춥니다. 중단된 모든 회차를 재실행하지 않고, 재시작 시 현재 예약 구간을 한 번 실행합니다. 실패한 구간은 자동 반복하지 않으므로 `지금 수집하기`로 재시도할 수 있습니다. 장기 운영에는 상시 실행 호스팅과 영구 디스크가 필요합니다. 기존 ChatGPT 예약과는 연결되어 있지 않으며 이메일·메신저 발송 기능은 아직 없습니다.

## 데이터와 백업

기본 저장 위치는 `.data/memory.db`이며 Git에서 제외됩니다. `MEMORY_DB`로 다른 영구 저장 경로를 지정할 수 있습니다. 저장된 목표주가와 기사 데이터가 있으므로 운영 시 이 파일을 백업하세요. 실행 중인 DB 백업에는 SQLite backup API를 사용하세요. 북마크는 해당 브라우저의 로컬 저장소에 보관됩니다.

## 검증 및 수동 수집

```bash
python -m unittest discover -s tests -v
python app.py --collect
```

`--collect`는 한 번 수집하고 종료합니다. 모든 피드 접근이 실패하면 종료 코드 1을 반환합니다. `--no-scheduler`는 예약 수집을 비활성화합니다. 상태 확인은 `GET /api/health`, 데이터 확인은 `GET /api/dashboard`를 사용하세요. 테스트는 임시 DB와 테스트 RSS만 사용하며 실제 저장 데이터에 영향을 주지 않습니다.

## 클라우드 환경

오라클 무료 서버를 보유한 경우 [오라클 배포 안내](deploy/ORACLE.md)를 참고하세요. 배포 설치기는 재부팅 후 자동 시작과 데이터 유지·백업을 설정합니다. 기본 접속은 SSH 터널 방식이며 공개 인터넷 접속은 별도 설정이 필요합니다.

기존 `/workspace/memory-report` 체크아웃을 사용하세요. 각 작업은 이미 격리되어 있으므로 요청 없이 Git worktree를 만들지 않습니다. 라이브 프로세스는 환경 게시나 새 작업에서 유지되지 않으므로 `python app.py --port 8000`을 다시 시작해야 합니다. 테스트 의존성도 Python 표준 라이브러리뿐입니다.
