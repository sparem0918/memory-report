# 메모리 브리프 · Memory Brief

**사이트 접속:** [Memory Brief 열기](https://memory-brief.129-225-146-56.sslip.io)

개인용 사이트로, 접속 시 설정한 사용자 이름과 비밀번호가 필요합니다.

삼성전자·SK하이닉스의 국내외 공개 뉴스와 목표주가 정보를 한곳에서 보는 개인용 웹 대시보드입니다. Python 3.11 이상을 사용하며 기본 수집에는 유료 API나 외부 Python 패키지가 필요하지 않습니다. 선택 기능인 Gemini 한국어 요약에는 별도의 Google AI Studio API 키가 필요합니다. 공개 리포트 PDF의 텍스트를 읽을 때는 무료 OS 패키지 `poppler-utils`가 필요하며 오라클 설치기가 자동 설치합니다.

## 실행

```bash
cd /workspace/memory-report
python app.py --port 8000
```

브라우저에서 실행한 서버의 포트 8000에 접속합니다. 기본 바인딩은 `127.0.0.1`입니다. 호스팅 환경에 배포할 때에는 해당 환경의 포트 전달 방식을 확인하고 필요하면 `--host 0.0.0.0`을 사용하세요. 현재 버전은 개인용이며 로그인 기능이 없습니다. 인터넷에 공개하기 전에 인증을 추가해야 합니다.

## 포함된 기능

- Google News RSS를 이용한 국내·해외 뉴스 수집: 기업별 국내 뉴스, 영어 뉴스, 목표주가 관련 뉴스 총 6개 피드
- 시작 시 현재 예약 구간 수집, 이후 매일 **한국 시간 오전 8시 / 오후 6시** 수집
- 지금 수집하기, 기사 제목·언론사 검색, 기업·지역·주제별 필터
- 제목·언론사가 같은 기사의 중복 저장 방지, HBM·DRAM·NAND·리포트 관련 기사 분류
- 최근 72시간 기사에서 주제와 출처를 분산한 핵심 기사 최대 3개 표시
- **선택 기능: Gemini 한국어 브리핑** — 핵심 변화, 기업별 의미와 다음 확인 사항, 출처 링크와 제목 기반 여부 표시
- 원문 출처·발표 시각 표시, 브라우저에 기사 북마크 저장
- **목표주가 자동 등록**: 공개 RSS 문구, 한국경제의 구조화된 공개 기사 본문, Npay 증권의 공개 종목 리포트 정보·PDF에서 명시된 정보를 추출
- 증권사·이전/변경 목표주가·투자의견·사유를 각각 확인하고 없는 항목은 `확인 필요` 표시
- 이전/변경 금액이 원문 문구 또는 동일 리포트의 공개 정보에서 함께 확인된 경우에만 변동률 계산, 원문 발췌·출처·기사일/리포트 등록일 구분 표시
- 원문 확인 후 목표주가·증권사·투자의견·변경 사유 수동 기록 및 삭제
- 자동 기록과 수동 기록 분리 저장, 자동 기록 숨김 상태 유지, 기존 기사에 대한 업그레이드 시 자동 소급 정리
- SQLite 영구 저장, 수집 실패 시 기존 데이터 유지, 수집 상태 표시
- 실제 데이터와 분리된 **예시 화면**: 가상 데이터는 DB에 저장되지 않습니다.

## 수집 범위와 제한

뉴스 수집에는 HTTPS `news.google.com` 접근이 필요합니다. 공개 리포트와 추가 기사 본문 수집에는 `www.hankyung.com`, `stock.naver.com`, `stock.pstatic.net`도 필요합니다. 도메인 허용 설정이 반영되지 않았다면 설정에서 허용하고 다시 수집하세요. 원문을 여는 사용자의 브라우저에서는 해당 언론사 접속도 필요할 수 있습니다.

기본 수집 범위는 최근 3일 뉴스, 최근 7일 목표주가 관련 뉴스입니다. Npay 증권 공개 리포트는 최근 14일 중 기업별 최신 3건을 읽고, 연결된 PDF 첫 페이지의 텍스트도 확인합니다. 구 네이버 금융 주소 대신 현재 공개 리포트 서비스의 조회 경로를 사용합니다. 로그인·쿠키·API 키가 필요하지 않은 공개 정보만 요청하며 조회수 등록 등 쓰기 요청은 하지 않습니다. 한국경제 추가 RSS는 최신 100건 중 해당 기업의 목표주가·투자의견 관련 기사를 대상으로 합니다. 본문 읽기는 회차당 최대 18건으로 제한합니다. 모든 기사나 모든 증권사 보고서를 포괄하지 않습니다. 유료·로그인 필요 자료의 접근 제한을 우회하지 않으며, 영어 기사는 원어로 표시합니다.

핵심 브리핑은 **기사 제목을 선별한 목록**이며, 생성형 AI의 본문 요약이나 투자 영향 분석이 아닙니다. 주제 분류는 제목 키워드 기반입니다. 같은 제목·같은 언론사의 중복은 제거하지만, 여러 매체가 표현을 바꿔 쓴 동일 사건은 별도 기사로 남을 수 있습니다. 주가·수익률 시세는 제공하지 않습니다.

목표주가 자동 정리는 규칙 기반이며, 명시된 원화 금액만 읽습니다. Npay 공개 정보의 `goalPrice`, `prevGoalPrice`는 해당 서비스 화면에 원 단위로 표시되는 필드만 사용합니다. `priceAtWriteDate` 같은 당시 주가는 목표가로 사용하지 않습니다. 달러 환산, 불명확한 단위 보충, 이전 저장값으로 종전 목표가 채우기, 누락된 사유 생성은 하지 않습니다. 여러 기업·증권사·서로 다른 수치가 섞여 확정하기 어렵거나, 본문과 공개 정보가 다르면 `확인 필요`로 남깁니다. PDF에 접근하지 못해도 공개 정보에 명시된 값은 표시하고, 없는 값은 비워 둡니다. Google RSS 설명의 다른 기사 목록은 근거로 사용하지 않습니다. PDF가 이미지뿐이거나 지원하지 않는 문서 배치라면 숫자를 읽지 못할 수 있습니다. `자동 추출`도 독립적 사실 검증을 뜻하지 않으며 항상 원문을 확인해야 합니다. `기사일`·`리포트 등록일`은 실제 원본 리포트 발표일과 다를 수 있습니다.

자동 행을 숨기면 같은 기사에 대한 후속 수집에서도 숨김을 유지합니다. 새 기사나 수정된 제목으로 수집된 별도 자료는 새 행이 될 수 있습니다. 공개 자료 수정 시 재수집한 문구를 다시 처리하지만, 현재 수집 범위를 벗어난 과거 자료의 개정까지 추적하지는 않습니다. 원문 접근 실패는 목표주가 영역의 수집 상태와 근거 설명에서 확인할 수 있습니다. 수동 기록은 자동 수집으로 수정하지 않습니다.

**정기 수집에는 서버가 계속 실행 중이어야 합니다.** 클라우드 작업이 종료되면 수집도 멈춥니다. 중단된 모든 회차를 재실행하지 않고, 재시작 시 현재 예약 구간을 한 번 실행합니다. 실패한 구간은 자동 반복하지 않으므로 `지금 수집하기`로 재시도할 수 있습니다. 장기 운영에는 상시 실행 호스팅과 영구 디스크가 필요합니다. 기존 ChatGPT 예약과는 연결되어 있지 않으며 이메일·메신저 발송 기능은 아직 없습니다.

## Gemini 한국어 브리핑 설정

기본 상태에서는 API를 호출하지 않습니다. 오라클 서버에 새 버전을 설치한 다음 실행하세요.

```bash
sudo python3 deploy/configure_gemini.py
```

[Google AI Studio](https://aistudio.google.com/api-keys)에서 무료 이용이 가능한 프로젝트의 키를 발급합니다. **결제 계정을 연결하지 마세요.** 무료 이용 가능 여부·한도와 데이터 이용 조건은 Google의 현재 정책을 확인하세요. 이 앱은 결제·구독을 활성화하지 않으며, 일일 호출 제한만으로 유료 프로젝트의 비용을 막을 수는 없습니다.

설정 도구는 모델 이름(기본 `gemini-3.5-flash-lite`, 이용 불가 시 AI Studio에서 확인한 무료 지원 모델로 변경 가능)과 API 키를 묻습니다. 키 입력은 화면에 표시되지 않습니다. 읽기 전용 모델 조회에 성공한 경우에만 `/etc/memory-brief/gemini.env`에 root 전용 권한 `0600`으로 저장하고 서비스를 재시작합니다. 키를 채팅·GitHub·명령행 인자로 전달하지 마세요. 실제 요약 생성 성공 여부는 웹사이트의 AI 브리핑 또는 상태 메시지에서 확인해야 합니다.

요약은 정기 수집(08:00/18:00 KST) 또는 `지금 수집하기` 후 서버에서 한 번 생성해 SQLite에 저장합니다. 페이지 조회·12초 화면 갱신은 저장된 결과만 읽습니다. 입력이 동일한 날에는 재사용하며, 실패와 대체 모델 호출을 모두 합쳐 한국 날짜 기준 최대 4회로 제한합니다. 수집 회차 사이에는 AI 생성 시도를 최소 15분 간격으로 제한합니다. Google이 구조화된 오류로 **모델별 일일 할당량 소진**을 알리면 같은 회차에서 `gemini-2.5-flash-lite`로 한 번 대체합니다. 분당 제한·키 오류·응답 검사 실패·모델과 무관한 프로젝트 공통 한도에는 전환하지 않습니다. 대체 호출도 앱의 하루 4회 제한 안에서만 실행합니다. 그날 이후에는 Lite를 우선 사용하고 다음 한국 날짜에는 기본 모델부터 다시 시도합니다. Google 할당량의 실제 초기화 시각은 한국 날짜와 다를 수 있습니다. Lite도 일일 한도가 소진되면 그날 추가 요청을 중단합니다. 반복 자동 재시도·검색/유료 도구 호출은 없습니다. 한도 초과·연결 실패 시 이전 AI 요약을 표시하고, 이전 요약도 없다면 기존 기사 제목 카드를 표시합니다.

공개 자료만 최대 24건(기업별 최대 12건), 최근 72시간의 제목과 이미 수집된 공개 발췌 일부를 Google로 전송합니다. 수동 목표주가 기록·개인 메모·API 키는 요약 입력에 포함하지 않습니다. 모든 기사 본문을 새로 읽는 기능은 아니며, 제목만 있는 출처는 `제목 기반`으로 표시합니다. Gemini는 핵심 변화·의미·다음 확인 사항을 한국어로 정리하며 목표주가 테이블을 수정하지 않습니다. 서버는 출처 ID·기업 구분·형식·출처에 없는 숫자를 점검하고 원문 링크를 직접 붙입니다. 이는 AI의 해석과 사실성을 완전히 검증한다는 뜻은 아닙니다. 개별 카드가 검사에 실패하면 그 카드만 제외하고, 기업별 요약이 없으면 근거 없는 내용을 채우지 않고 `확인 필요`로 표시합니다. 검사를 통과한 카드가 하나도 없으면 이전 브리핑을 유지합니다. 영문 약어 제목은 허용하되 설명 본문에는 한국어가 필요합니다. `gemini-2.5-flash` 계열에는 `thinkingBudget=0`을 적용해 짧은 JSON 요약의 출력 한도가 추론으로 소진되는 것을 방지합니다.

일시 중단하려면 `sudo systemctl edit memory-brief`에서 아래 설정을 추가하고 재시작하세요. API 키 파일 자체를 삭제할 필요는 없습니다.

```ini
[Service]
UnsetEnvironment=GEMINI_API_KEY
```

```bash
sudo systemctl restart memory-brief
```

## 데이터와 백업

기본 저장 위치는 `.data/memory.db`이며 Git에서 제외됩니다. `MEMORY_DB`로 다른 영구 저장 경로를 지정할 수 있습니다. 저장된 목표주가와 기사 데이터가 있으므로 운영 시 이 파일을 백업하세요. 실행 중인 DB 백업에는 SQLite backup API를 사용하세요. 북마크는 해당 브라우저의 로컬 저장소에 보관됩니다.

자동 정리 업데이트는 기존 `articles`, `targets` 테이블의 스키마와 수동 기록을 유지하면서 `report_inputs`, `auto_targets` 테이블을 추가합니다. 새 버전 시작 시 기존 최근 기사부터 네트워크 요청 없이 소급 정리하고, 예약 수집이 켜져 있으면 새 추출 버전의 전체 수집도 한 번 실행합니다. 오라클 서버 업데이트는 `git pull --ff-only` 후 `sudo bash deploy/install.sh`로 진행하며, 기존 Caddy 로그인·HTTPS 설정은 다시 입력하지 않습니다.

## 검증 및 수동 수집

```bash
python -m unittest discover -s tests -v
python app.py --collect
```

`--collect`는 뉴스와 목표주가를 한 번 수집하고 종료합니다. 모든 뉴스 피드 접근이 실패하면 종료 코드 1을 반환합니다. 추가 공개 자료의 실패는 `target_collection.errors`로 별도 보고합니다. `--no-scheduler`는 예약 수집을 비활성화합니다. 상태 확인은 `GET /api/health`, 자동 목표가를 포함한 데이터 확인은 `GET /api/dashboard?target_format=2`를 사용하세요. 구형 클라이언트가 누락된 값을 0원으로 표시하지 않도록, 쿼리 없는 기존 `/api/dashboard`는 수동 기록만 반환합니다. 테스트는 임시 DB·테스트 RSS·작은 테스트 PDF를 사용하며 실제 저장 데이터에 영향을 주지 않습니다. 실제 PDF 변환 테스트에는 `pdftotext`가 필요합니다.

Gemini가 설정되어 있으면 `--collect`가 요약도 갱신합니다. `--brief-only`는 저장된 공개 자료만 사용해 요약을 시도하며 동일한 캐시·호출 제한을 적용합니다. 단위 테스트는 모의 Gemini 응답을 사용하고 실제 API 키·요금을 사용하지 않습니다. 실제 모델 이용 가능 여부와 생성 성공 여부는 서버에서 키를 등록한 뒤 별도로 확인해야 합니다.

## 클라우드 환경

오라클 무료 서버를 보유한 경우 [오라클 배포 안내](deploy/ORACLE.md)를 참고하세요. 배포 설치기는 재부팅 후 자동 시작과 데이터 유지·백업을 설정합니다. 기본 접속은 SSH 터널 방식이며 공개 인터넷 접속은 별도 설정이 필요합니다.

기존 `/workspace/memory-report` 체크아웃을 사용하세요. 각 작업은 이미 격리되어 있으므로 요청 없이 Git worktree를 만들지 않습니다. 라이브 프로세스는 환경 게시나 새 작업에서 유지되지 않으므로 `python app.py --port 8000`을 다시 시작해야 합니다. 테스트 의존성도 Python 표준 라이브러리뿐입니다.

Gemini 오류 진단은 서버의 체크아웃 폴더에서 아래 읽기 전용 명령으로 확인합니다. API 호출 없이 상태·오류 코드·모델·오늘 시도 횟수·다음 시도 가능 시각만 표시하며 키·원본 응답·전체 요약은 출력하지 않습니다. `finish_MAX_TOKENS`는 출력 중단, `invalid_json`은 JSON 형식 오류, `no_verified_items`와 `checks`는 카드별 검사 실패를 뜻합니다. 이미 저장된 API 키는 앱 업데이트 후에도 유지됩니다.

```bash
python3 deploy/gemini_status.py
```
